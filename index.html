    The act that creates value is the act that creates exposure

    An employee who writes an effective prompt and one who leaks sensitive data may be performing the identical action. In 2023, engineers at a major electronics manufacturer pasted proprietary source code into a public chatbot while debugging. Nobody breached anything.

    So control presence is the wrong unit

    Two organizations can hold identical controls while one suppresses use into unmonitored channels and the other keeps it observable.

    Every safeguard setting fixes an operating point between two failures

    Miss

    The system assists a request it should have refused.

    Over-refusal

    It declines a request it should have served: degrades the product, pushes users to less governed tools.

    The correct operating point depends on class priors and misclassification costs, which vary by deployment (Provost & Fawcett 2001; Elkan 2001). Evaluations report aggregate scores used to rank models, with no path to the configuration decision.

    "Toggling is a semi-structured decision: compute what can be computed, make judgments explicit, route the ambiguous cases to a person."

    SCDS: four layers from evaluation evidence to a recorded decision

    Evidence

    Per category: coverage rH, over-refusal rB, robustness ρ. Vectors, not one score.

    Context

    Harmful-intent prior π, adversarial pressure α, cost ratio λ = Cmiss/Cref, hard constraints.

    Decision

    Expected cost per setting; permissibility scalar p; deliberation band for humans.

    Accountability

    A rationale record: sources, parameters, who supplied them, decision.

    r(s) = (1 − α)·rᴴ(s) + α·ρ(s) E[C(s)] = π·(1 − r(s))·λ + (1 − π)·rᴮ(s) p = E[C(restrictive)] / (E[C(restrictive)] + E[C(permissive)])

    p near 1: the restrictive setting is the costly one, so permit. Near 0: refuse. Inside the band [0.40, 0.60]: a person decides, shown which parameter the case turns on.

    Costs in units of C^ref, so only λ matters.

    Unvalidated instruments

    Machine-targeted fraud: the intended audience is the delegated agent

    Fraud research studies a human victim: attention, trust, cognitive bias. Transactions are moving to AI agents that read email, compare offers, negotiate and pay, with limited human review. Deception now has to fool a model.

    Definition

    Deliberate deception of a delegated decision maker for gain, where the principal bears the loss.

    Not: fraud using AI as a tool

    The human is still the victim.

    Not: models deceiving on their own account

    The model is the deceiver, not the deceived.

    What's new is the victim

    Indirect prompt injection (Greshake et al. 2023) has been treated as a software defect. We treat it as fraud.

    Trust mechanisms and dark patterns were calibrated to human readers

    Principal-agent

    The principal cannot observe the agent's inputs (Jensen & Meckling 1976). Now the agent is software reading pages the principal never sees.

    E-market trust

    Reputation and escrow were built for human readers (Ba & Pavlou 2002). How agents weigh them is unknown.

    Dark patterns

    Tuned to human cognition (Mathur et al. 2019). Model-calibrated counterparts: irrelevant to people, decisive for agents.

    Victim typologies must be re-derived: no emotions, a strong instruction-following bias.
