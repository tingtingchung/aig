# Talk demos — ICIS 2026

Interactive demos that replace slides for five talks:

- Governance-Grade Benchmarks (Dec 4, 5 min)
- Between Leverage and Leakage / GUARD (SIGDSA, Dec 12)
- Refuse or Permit? Configuring AI safeguards (SIGDSA, Dec 12)
- From Leaderboards to Instruments (WISP, Dec 12)
- When the Mark Is a Machine (TREO, Dec 13)

Live site: https://tingtingchung.github.io/aig/

One self-contained `index.html`, no build step. Open it locally to present offline.

Presenter keys: ← → step · 1–9 jump · T timer · R reset step · N speaker notes · F full screen.

Numbers marked "sample" or "illustrative" on screen are not research findings.
